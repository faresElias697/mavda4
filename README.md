# student_grades

A small Flutter app (Hebrew, right-to-left) that lists students and their grades.

- Shows the class average at the top (ממוצע).
- Each student has a ✓ (passed, 55 and up) or ✗ (failed) icon.
- `+` / `−` buttons raise or lower a grade (0–100); the average and pass/fail update live.
- The sort button cycles: high → low, low → high, original order.

## Run

```bash
flutter run
```
